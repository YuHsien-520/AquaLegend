# AquaLegend

AquaLegend 是面向 Minecraft Java Edition 1.12.2 / CatServer 的大型钓鱼玩法插件。

本仓库用于长期保存 AquaLegend 从早期版本到当前版本的源码与版本资料，目录组织参考 YXLand：历史版本统一放在 `versions/<version>/` 下，便于回溯、比较和继续开发。

## 当前版本

- 当前稳定版本：`2.5.4`
- Minecraft：`1.12.2`
- Java：`8`
- 服务端：Bukkit / Spigot API，重点兼容 CatServer 1.12.2

## 目录说明

```text
AquaLegend/
├─ README.md
├─ CHANGELOG.md
└─ versions/
   ├─ 2.1.1/
   ├─ 2.2.0/
   ├─ ...
   └─ 2.5.4/
```

每个版本目录尽量保留当时真实的：

- `src/` Java 源码与资源配置
- `pom.xml`
- `tools/` 测试与辅助脚本
- `docs/` 设计与实施文档
- `README.md` / `INSTALL-*.md` / `TEST_REPORT-*.md` / `PROJECT_HANDOFF-*.md`（该版本源码包中存在时）

为避免仓库污染，第三方 SDK/JAR、编译产物、缓存文件与大体积二进制生成物不会作为“源码”重复提交。

## 注意

历史版本按当时真实状态归档，可能包含后来被移除或替换的实验性实现。请优先使用最新稳定版本进行实际部署。
